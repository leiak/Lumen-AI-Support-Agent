# M5.3 — Tenant LLM Config Audit Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an append-only audit log for every change to `tenant_llm_configs` made via the admin REST surface, plus a `GET /admin/tenants/{id}/llm-configs/audit` endpoint to read it. Closes README tech debt line 372.

**Architecture:** New `tenant_llm_config_audit_log` table (one row per field change) + `TenantLLMConfigAuditRepository`. The `AdminTenantLLMConfigRepository` wrapper is rewritten to own its own session, fetch the old row, call the inner repo without committing, compute diffs, and INSERT audit rows — all in one transaction (atomicity guarantee). The inner `TenantLLMConfigRepository.upsert/update/delete_by_tenant_provider` methods gain an optional `session` param so the wrapper can pass its own (back-compat: `None` keeps today's self-managed behavior). `claims["sub"]` flows through routes → wrapper as `changed_by`. Plaintext `api_key` is hashed at the route layer (SHA-256) and stored in the audit row as `sha256:<hex>`.

**Tech Stack:** Python 3.11 + SQLAlchemy 2.1.4 async + Postgres + Pydantic v2 + pytest-asyncio. Mirrors M4.C `tenant_llm_configs` (extends) + M4.D `tenant_budget_credits` (immutable audit row pattern).

```python
"""ORM + repository for ``tenant_llm_config_audit_log`` (M5.3).

Append-only audit log of every field change made via the admin
REST surface to ``tenant_llm_configs``. One row per field change
(``field`` is one of ``api_key`` | ``base_url`` | ``model`` |
``enabled`` | ``__deleted__``).

Mirrors the immutable-row pattern from
:mod:`budget.models.TenantBudgetCredit` (M4.D Pack B). The app
never UPDATEs or DELETEs audit rows; retention is forever (manual
SQL cleanup if needed).
"""
from __future__ import annotations

from datetime import datetime
from typing import Literal

from pydantic import ValidationError
from sqlalchemy import (
    DateTime,
    ForeignKey,
    String,
    Text,
    func,
    select,
)
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy.orm import Mapped, mapped_column

from core.database import Base

# Field value space — Pydantic Literal enforces this at ORM __init__
# time so a typo never reaches the DB. DB column is just VARCHAR(32).
FieldName = Literal[
    "api_key",
    "base_url",
    "model",
    "enabled",
    "__deleted__",
]


class TenantLLMConfigAuditLog(Base):
    """One row per field change to a tenant's LLM config.

    INSERT-only. The app has no UPDATE/DELETE on this table.

    Foreign keys:
    * ``tenant_id`` -> ``tenants.id`` ON DELETE CASCADE — when a
      tenant is dropped, its audit history goes with it.

    No FK to ``tenant_llm_configs`` by design: deleting a source
    row must NOT cascade the audit (the audit is the historical
    record of that deletion).
    """

    __tablename__ = "tenant_llm_config_audit_log"

    id: Mapped[str] = mapped_column(String(26), primary_key=True)
    tenant_id: Mapped[str] = mapped_column(
        ForeignKey("tenants.id", ondelete="CASCADE"),
        nullable=False,
    )
    provider_name: Mapped[str] = mapped_column(String(64), nullable=False)
    field: Mapped[str] = mapped_column(String(32), nullable=False)
    old_value: Mapped[str | None] = mapped_column(Text, nullable=True)
    new_value: Mapped[str | None] = mapped_column(Text, nullable=True)
    changed_by: Mapped[str] = mapped_column(String(64), nullable=False)
    changed_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True),
        server_default=func.now(),
        nullable=False,
    )

    def __init__(self, **kwargs: object) -> None:
        # Enforce Literal validation on ``field`` so a typo at the
        # ORM boundary never writes a bogus value to the DB column.
        field = kwargs.get("field")
        if field is not None:
            try:
                # Pydantic v2 Literal validation
                from pydantic import TypeAdapter

                TypeAdapter(FieldName).validate_python(field)
            except ValidationError as exc:
                raise ValueError(
                    f"invalid field value {field!r}; "
                    f"must be one of {list(FieldName.__args__)}"
                ) from exc
        super().__init__(**kwargs)


class TenantLLMConfigAuditRepository:
    """CRUD for ``TenantLLMConfigAuditLog`` rows.

    All mutating + reading methods take an explicit ``AsyncSession``
    so the wrapper can compose audit writes into the same
    transaction as the mutation (atomicity guarantee — see spec §4
    and §8).
    """

    async def insert_many(
        self,
        session: AsyncSession,
        rows: list[TenantLLMConfigAuditLog],
    ) -> None:
        """Batch insert audit rows. Caller owns the transaction (no commit)."""
        if not rows:
            return
        session.add_all(rows)
        await session.flush()

    async def list_by_tenant(
        self,
        tenant_id: str,
        *,
        provider_name: str | None = None,
        limit: int = 50,
        offset: int = 0,
    ) -> list[TenantLLMConfigAuditLog]:
        """List audit rows newest-first. Optional provider_name filter.

        Caller-managed session (no commit). Returns the page slice
        ordered by ``changed_at DESC``.
        """
        stmt = select(TenantLLMConfigAuditLog).where(
            TenantLLMConfigAuditLog.tenant_id == tenant_id,
        )
        if provider_name is not None:
            stmt = stmt.where(
                TenantLLMConfigAuditLog.provider_name == provider_name,
            )
        stmt = (
            stmt.order_by(TenantLLMConfigAuditLog.changed_at.desc())
            .limit(limit)
            .offset(offset)
        )
        result = await session.execute(stmt)
        return list(result.scalars().all())

    async def count_by_tenant(
        self,
        tenant_id: str,
        *,
        provider_name: str | None = None,
    ) -> int:
        """Total rows for the same WHERE clause as ``list_by_tenant``.

        Caller-managed session. Used to populate the
        ``{entries, total}`` envelope on the GET endpoint.
        """
        from sqlalchemy import func as sa_func

        stmt = select(sa_func.count(TenantLLMConfigAuditLog.id)).where(
            TenantLLMConfigAuditLog.tenant_id == tenant_id,
        )
        if provider_name is not None:
            stmt = stmt.where(
                TenantLLMConfigAuditLog.provider_name == provider_name,
            )
        result = await session.execute(stmt)
        return int(result.scalar() or 0)


__all__ = [
    "FieldName",
    "TenantLLMConfigAuditLog",
    "TenantLLMConfigAuditRepository",
]
```

`upsert` (lines 87-136): change to:

```python
    async def upsert(
        self,
        *,
        tenant_id: str,
        provider_name: str,
        encrypted_api_key: bytes,
        base_url: str | None,
        enabled: bool = True,
        model: str | None = None,
        session: AsyncSession | None = None,
    ) -> TenantLLMConfig:
        """Insert or update a (tenant_id, provider_name) row.

        Uses INSERT ... ON CONFLICT (Postgres-specific) for atomicity.
        The unique constraint enforces one row per pair.

        ``model`` is the M5.2 per-tenant model override. ``None`` (the
        default) means "no override; project default applies". Existing
        callers that don't pass ``model`` keep their current behavior
        (NULL column = no override).

        ``session``: M5.3 — when provided, the call uses the caller's
        session and does NOT commit (caller owns the transaction).
        When ``None`` (default, back-compat for seed script + tests),
        the call opens its own session and commits at the end.
        """
        stmt = (
            pg_insert(TenantLLMConfig)
            .values(
                id=new_id(),
                tenant_id=tenant_id,
                provider_name=provider_name,
                encrypted_api_key=encrypted_api_key,
                base_url=base_url,
                model=model,
                enabled=enabled,
            )
            .on_conflict_do_update(
                constraint="uq_tenant_llm_configs_tenant_provider",
                set_={
                    "encrypted_api_key": encrypted_api_key,
                    "base_url": base_url,
                    "model": model,
                    "enabled": enabled,
                    "updated_at": func.now(),
                },
            )
            .returning(TenantLLMConfig)
        )
        if session is not None:
            # Caller-managed transaction.
            result = await session.execute(stmt)
            row_obj = result.scalar_one()
            await session.flush()
            await session.refresh(row_obj)
            return row_obj
        # Back-compat path: own session + commit.
        sm = get_sessionmaker()
        async with sm() as own_session:
            result = await own_session.execute(stmt)
```

```python
def _diff_upsert(
    *,
    old: TenantLLMConfig | None,
    payload_model_fields_set: set[str] | None,
    new_base_url: str | None,
    new_model: str | None,
    new_enabled: bool | None,
    new_api_key_sha256: str | None,
) -> list[tuple[str, str | None, str | None]]:
    """Produce list of (field, old_repr, new_repr) audit tuples.

    Behavior (M5.3 spec §6.5):
    - POST (insert): ``payload_model_fields_set=None`` → diff all
      fields. ``old is None``, so every field's old_repr is None
      (or the literal "sha256:initial" for api_key).
    - PATCH: ``payload_model_fields_set`` is the set of fields in
      the payload. Each field is included in the diff ONLY if its
      new value differs from the DB row's old value.
    - DELETE is not handled here; wrapper writes ('__deleted__',
      provider, None) directly.

    ``new_api_key_sha256`` is required on POST (passed by the route
    layer after computing ``hashlib.sha256(plaintext).hexdigest()``)
    and is None on PATCH (PATCH never rotates the key).
    """
    diffs: list[tuple[str, str | None, str | None]] = []

    # --- api_key ---
    # POST always has a new SHA-256; PATCH never does. On insert, the
    # old_repr is the sentinel "sha256:initial" (not None — the spec
    # wants a first-class audit record of the initial key).
    if new_api_key_sha256 is not None:
        if old is None:
            diffs.append(("api_key", "sha256:initial", new_api_key_sha256))
        else:
            # The previous audit row stored the OLD plaintext's hash;
            # we don't have it here, so we can only record the NEW
            # hash. A "key was rotated" event with old=None is still
            # useful: it confirms a rotation happened. The previous
            # hash can be reconstructed by reading the most recent
            # prior audit row's ``new_value`` for the same (tenant,
            # provider, field=api_key).
            diffs.append(("api_key", None, new_api_key_sha256))

    # --- base_url / model / enabled ---
    # On POST (fields_set=None) we always include these. On PATCH we
    # only include fields the operator actually sent.
    def _maybe(
        field_name: str,
        new_value: str | None,
        old_value: str | None,
    ) -> None:
        if payload_model_fields_set is not None and field_name not in payload_model_fields_set:
            return
        if old is None:
            # Insert — every non-key field is "new". The diff is
            # always written because the value is brand-new (None →
            # something).
            diffs.append((field_name, None, new_value))
        else:
            if new_value != old_value:
                diffs.append((field_name, old_value, new_value))

    _maybe("base_url", new_base_url, old.base_url if old else None)
    _maybe("model", new_model, old.model if old else None)
    _maybe(
        "enabled",
        str(new_enabled) if new_enabled is not None else None,
        str(old.enabled) if old else None,
    )
    return diffs
```

```python
        # check; we never call its list() because we don't need the
        # current state, just confirmation the tenant exists.
```

```markdown
**How to apply**

- **Atomicity is the M5.3 contract** — never split mutation and audit into separate transactions. Future callers adding new write paths to `tenant_llm_configs` MUST go through the wrapper, not directly through the inner repo, or they bypass audit.
- **Back-compat pattern for the inner repo** — `session: AsyncSession | None = None`. When `None`, retain the self-managed session+commit behavior (extend-seed.py relies on this). When provided, caller owns the transaction.
- **DELETE doesn't audit `api_key`** — the wrapper can't hash old plaintext at the wrapper layer (it's already encrypted by then). The audit shows the deletion event via the `__deleted__` sentinel row. If you need to track key rotations specifically, query audit rows with `field='api_key'` in chronological order; the `new_value` carries the post-rotation hash.
- **Field values are Pydantic-Literal, not DB enum** — adding a new field value (e.g. `temperature`) is a code-only change, not a migration. The DB column is just `VARCHAR(32) NOT NULL`.
- **No retention cleanup worker** — audit rows are forever. Operators run `DELETE FROM tenant_llm_config_audit_log WHERE changed_at < now() - interval '90 days'` if needed. (Future M5.3+ work if disk pressure becomes real.)
- **No audit for non-admin sources** — `extend-seed.py` writes to `tenant_llm_configs` without going through the admin wrapper, so its writes do NOT appear in the audit log. If you need to instrument seed scripts or future bulk paths, add a second caller that threads `changed_by="system:<source>"` through the same wrapper.
```
